# M1.1 — optional BotAI integration

Engo can optionally use BotAI v1 without making AI part of the IRC bot core.

Configuration:

```sh
ENGO_BOTAI_URL=http://botai:8090
ENGO_BOTAI_EXPERT=auto
ENGO_BOTAI_TIMEOUT=30s
```

If `ENGO_BOTAI_URL` is unset, Engo performs no BotAI initialization and has
no AI command.

When configured, Engo checks BotAI API compatibility at IRC-session startup.
An unreachable, timed-out or incompatible BotAI instance disables the AI
integration for that session; it does not prevent IRC connection, scripts,
commands or PBMP from operating.

When enabled:

```text
!ai <message>
```

sends the message to BotAI using the configured expert. The default expert is
`auto`. A request failure returns a short availability notice to the caller
without disconnecting IRC.

M1.1 intentionally does not add conversation memory. Context/history and
automatic conversational participation are later milestones.
