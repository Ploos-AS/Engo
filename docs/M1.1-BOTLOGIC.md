# M1.1 — BotLogic integration

Engo can optionally use BotLogic API v1 for symbolic reasoning.

Configuration:

- `ENGO_BOTLOGIC_URL` enables the integration.
- `ENGO_BOTLOGIC_RULESET` selects the ruleset (default `irc-policy`).
- `ENGO_BOTLOGIC_TIMEOUT` sets the request timeout (default 2s).

When enabled, Engo verifies `GET /v1/version` reports service `botlogic` and API `v1`.

The `!logic <query>` command sends a query to the configured ruleset and reports the snapshot revision and solution count.

## Standalone-first boundary

BotLogic is optional. If it is absent, unreachable, misconfigured or API-incompatible:

- Engo still starts and connects to IRC;
- scripts and ordinary commands continue to work;
- BotAI remains independent;
- PBMP remains independent;
- only BotLogic-backed functionality is unavailable.

Engo does not require BotWeb or PBMP to communicate with BotLogic.
