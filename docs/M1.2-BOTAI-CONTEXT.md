# M1.2 — bounded conversation context

Engo owns BotAI conversation context. BotAI remains stateless.

`ENGO_BOTAI_HISTORY_MESSAGES` controls how many previous user/assistant
messages are sent with each `!ai` request. The default is 10 and the allowed
range is 0 through 20. Zero disables history.

Context is memory-only and disappears on Engo restart or IRC-session rebuild.
It is not written to the script state store, PBMP, BotWeb or BotAI.

Conversation scopes are:

- channel messages: one context per channel;
- private messages: verified IRC account when available;
- private messages without a verified account: nick fallback.

Only successful exchanges are retained. Failed BotAI calls do not modify
history.

`!aireset` clears the current conversation scope.

This milestone intentionally keeps context explicit, bounded and bot-owned.
