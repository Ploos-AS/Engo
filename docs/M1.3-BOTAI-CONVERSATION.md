# M1.3 — opt-in natural conversation

Natural BotAI conversation is disabled by default.

Enable it together with BotAI:

```sh
ENGO_BOTAI_URL=http://botai:8090
ENGO_BOTAI_CONVERSATION=1
```

When enabled, Engo invokes BotAI for:

- normal private messages to the bot;
- channel messages beginning with the bot nick followed by `:`, `,` or a space.

Examples: `Engo: explain SASL` and `engo, hello`.

Messages beginning with the command prefix are excluded so normal Engo/Tengo
commands retain their existing behavior. Ordinary channel conversation that
does not address Engo is also ignored.

Natural conversation uses the same bounded, memory-only M1.2 context and
configured expert as `!ai`. Provider errors are fail-open: they are logged
without disconnecting IRC or generating repeated channel error messages.

Built-in BotAI commands and handlers are stored separately from the Tengo
registry so script load/reload cannot remove them.
