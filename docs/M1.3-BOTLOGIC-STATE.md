# M1.3 — BotLogic IRC state feed

**M1.3 — PASS.**

Engo can publish selected live IRC state to the configured BotLogic ruleset through the structured fact batch API.

Initial facts:

- `online(Nick)`
- `channel_member(Channel, Nick)`
- `authenticated(Nick, Account)` only when Engo has verified account provenance

JOIN asserts membership and online state. PART retracts membership. ACCOUNT can assert a verified account mapping. QUIT retracts online/authentication state that Engo can prove, but does not guess channel membership without a complete membership index.

## Trust boundary

Account facts are never generated from an unverified account value. Nick and channel names are state, not authorization identities.

BotLogic receives structured facts through `/v1/facts/batch`; Engo does not generate Prolog source from IRC input.

## Failure semantics

State synchronization is optional and fail-open. A BotLogic timeout, HTTP error or service outage is logged and does not terminate the IRC session or disable ordinary Engo functionality.

BotAI, PBMP and BotWeb remain independent.
