# M1.4 — Complete BotLogic IRC membership state

**M1.4 — PASS.**

Engo now maintains a small in-memory IRC membership index for the optional BotLogic state feed.

It produces structured fact transactions for:

- JOIN — add channel membership and online state;
- PART — remove channel membership;
- KICK — remove the kicked nick from the affected channel;
- NICK — move all known memberships, online state and known verified account state to the new nick;
- QUIT — remove every known channel membership plus online and known account state;
- ACCOUNT — replace or remove verified account state.

The index makes QUIT cleanup deterministic instead of guessing which channels a nick occupied.

## Trust and failure boundaries

The index tracks observed IRC state only. Account authorization still requires verified provenance from Engo's bot layer. BotLogic remains optional and state synchronization remains fail-open: synchronization failure is logged but cannot terminate the IRC session.

All updates use BotLogic's structured fact API; IRC text is never emitted as Prolog source.
