# M1.5 — BotAI PBMP observability

Engo exposes read-only BotAI operational state through PBMP/1 method
`botai.status`. This allows BotWeb or another PBMP client to display AI health
without becoming part of the BotAI data path.

The result contains operational metadata only:

- enabled and API compatibility state;
- BotAI API contract version;
- natural-conversation mode;
- configured history bound, concurrency bound and cooldown;
- aggregate request, error and limiter counters;
- current in-flight request count.

The endpoint does not expose the BotAI URL, credentials, prompts, IRC message
content or conversation history.

PBMP remains optional. BotAI operation is unchanged when no PBMP socket or
BotWeb instance exists.
