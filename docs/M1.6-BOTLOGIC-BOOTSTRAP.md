# M1.6 — BotLogic IRC state bootstrap

**M1.6 — PASS.**

Engo now bootstraps the optional BotLogic membership/role model from IRC NAMES replies.

- numeric `353` accumulates a per-channel snapshot;
- multiple `353` lines are combined;
- numeric `366` marks the snapshot complete and triggers reconciliation;
- members missing from the completed snapshot are retracted;
- newly observed members are asserted;
- standard `@` operator and `+` voice prefixes populate `channel_operator/2` and `voiced/2`;
- stale role facts are retracted during reconciliation.

No partial NAMES response is treated as authoritative before `366`.

This provides a useful baseline after connect/reconnect without requiring WHO/WHOX support. Verified account facts remain event/provenance based and are not inferred from NAMES.

The BotLogic feed remains optional, structured and fail-open.
