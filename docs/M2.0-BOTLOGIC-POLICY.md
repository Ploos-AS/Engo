# M2.0 — Reference IRC policy

Engo ships a reference BotLogic policy in `rulesets/irc-policy.pl` plus an explainable companion.

## Security invariant

BotLogic is a second restrictive gate. It cannot grant a command that Engo's local `ENGO_ACCOUNT_PERMISSIONS` / `ENGO_COMMAND_PERMISSIONS` model did not already authorize.

The reference ruleset is deny-by-default: its command classes contain no real commands until an operator explicitly declares them.

A BotLogic grant requires a verified `authenticated(Nick, Account)` fact and one of:

- an explicit `account_command(Account, Command)` grant while the nick is online;
- a matching `operator_command(Command)` and observed channel operator role;
- a matching `voiced_command(Command)` and observed voice role.

Observed channel roles never replace verified services-account identity.

The companion rules expose stable textual proof identifiers for explainable policy evaluation.

M2.0 is complete when repository CI is green with these policy assets.
