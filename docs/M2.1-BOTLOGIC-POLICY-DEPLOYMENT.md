# M2.1 — BotLogic policy deployment lifecycle

**M2.1 — PASS.**

Engo can explicitly deploy a local policy file to the configured BotLogic ruleset through the stable `POST /v1/consult` API.

Configuration:

- `ENGO_BOTLOGIC_POLICY_FILE` selects the local Prolog source.
- `ENGO_BOTLOGIC_DEPLOY_POLICY=1` explicitly enables deployment.
- Merely setting a policy file does not mutate BotLogic.
- Deployment requires `ENGO_BOTLOGIC_URL` and a non-empty policy file setting.

Before IRC operation, Engo verifies BotLogic v1 compatibility, reads the policy, enforces BotLogic's 64 KiB consult limit, and consults the configured ruleset. An explicitly requested deployment that cannot be read or consulted fails startup rather than silently running a different policy.

Normal BotLogic runtime/state synchronization remains optional and fail-open after successful startup.
