# M2.2 — BotLogic policy preflight

**M2.2 — PASS.**

Policy deployment now has a local preflight before the stable BotLogic `/v1/consult` compile/activation gate.

The preflight rejects:

- missing or unreadable policy files;
- empty source;
- source larger than BotLogic's 64 KiB consult limit;
- policy source without the required `may_execute/2` contract.

The reference policy also ships an acceptance matrix covering local denial, deny-by-default, explicit account grants, authenticated operator/voice grants, unauthenticated role denial, and offline explicit-account denial.

BotLogic v1 currently exposes no staging/delete-ruleset API. Engo therefore does not fake a remote dry-run by consulting a temporary persistent ruleset. Remote Prolog syntax/compile validation remains BotLogic's atomic consult operation; local preflight catches deployment mistakes that can be identified without mutating BotLogic.

Repository CI, Alpine OCI build and PBMP qualification are green.
